# ⚡ JYUN.ai - Assistente Virtual Interativo

O **JYUN.ai** é um chatbot interativo com temática *Cyberpunk/Dark Mode* desenvolvido para funcionar como assistente virtual do desenvolvedor **Renan Jyun (Dev JYUN)**. O sistema responde a dúvidas sobre o seu percurso, competências e direciona os utilizadores para o seu formulário de contacto.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica de toda a interface do chat e modais.
- **CSS3**: Estilização personalizada, temas escuros com iluminação neon cyan e animações.
- **JavaScript (ES6+)**: Animação em Canvas (Efeito Matrix), lógica de processamento de mensagens, tratamento de quebras de linha e conversão automática de links.
- **Bootstrap 5**: Layout responsivo, componentes visuais e modais de configuração.

---

## 🚀 Destaques do Projeto

- **Efeito Matrix:** Animação dinâmica desenhada via Canvas no fundo da aplicação.
- **Respostas Formatadas:** Tratamento de texto em tempo real para manter listas organizadas e URLs clicáveis.
- **Design Responsivo:** Interface adaptada para diferentes tamanhos de ecrã com Bootstrap.
